# Сайт «Услуги под ключ»

Статический сайт (HTML + CSS + JS, без сборки), публикуется через GitHub Pages из ветки `main`.

Этот репозиторий обычно лежит в папке `site/` внутри рабочего проекта. Полный контекст, правила работы
и скрипты — в `../CLAUDE.md` рабочего проекта. Если его нет рядом — спроси пользователя, прежде чем что-то менять.

Коротко:
- `index.html` — главная, `cases/*.html` — страницы кейсов, `css/styles.css`, `js/main.js`, `assets/img/` (WebP).
- После правок CSS/JS увеличь версию `?v=N` в `<link>` и `<script>` во всех html-страницах.
- Отвечай пользователю на русском.
