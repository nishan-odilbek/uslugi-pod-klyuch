# Услуги под ключ — сайт-портфолио

Статический сайт (HTML + CSS + JS), без сборки.

- `index.html` — главная
- `cases/` — страницы кейсов (AllStars, Trido)
- `css/styles.css` — стили
- `js/main.js` — скрипты
- `assets/` — логотип и картинки (webp)

## Запуск локально

```
python -m http.server 8080
```
и открыть http://localhost:8080

## Публикация

GitHub Pages из ветки `main` (корень). Каждый пуш в `main` обновляет сайт.
